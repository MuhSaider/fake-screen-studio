# Scenario berupa JSON tervalidasi, bukan kode

Scenario ditulis sebagai file JSON yang divalidasi terhadap skema dan terhadap component registry (action types, zoom preset, window template yang terdaftar) sebelum render — bukan sebagai kode seperti Remotion (`<Sequence>` dalam komponen). Alasannya: penulis utama scenario adalah AI agent, dan data lebih aman diedit (tidak ada risiko kode berbahaya atau crash saat preview), lebih mudah divalidasi dengan pesan error yang jelas, dan lebih mudah di-revisi sebagian tanpa menyentuh kode. Kekurangannya (efek yang tidak tercakup data) ditangani lewat escape hatch: efek baru ditulis sebagai kode yang **wajib didaftarkan ke registry** dulu, lalu baru dipakai dari JSON — sehingga indeks komponen yang dibaca agent tidak pernah basi.
